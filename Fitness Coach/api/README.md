# APIs de Fitness Coach

Capacidades previstas: `archivos-locales`, `google-calendar`, `opengym`, `garmin`. Consulta el [estado y fuentes](../../conexiones/catalogo.json) antes de elegir un ejecutor.

Prefiere el plugin conectado que ofrece la acción. Una sesión de Codex y un proceso Node independiente no comparten automáticamente OAuth. No hay clientes API ni tokens locales añadidos por este proyecto. Para una API nueva, verifica documentación, cuenta, alcance y variables de entorno; registra una prueba real sin secretos en reportes.
