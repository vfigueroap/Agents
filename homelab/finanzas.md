# Finanzas

Aplica el catálogo Finanzas y la skill personal-os-dashboard. Lee únicamente las capturas financieras y estados autorizados. Extrae movimientos como borradores con moneda, fecha y fuente; evita duplicar notificación y comprobante de la misma operación.

Un movimiento no acredita saldo disponible. Publica valuations solo cuando un estado, snapshot o fuente autorizada pruebe el saldo o valoración fechada. Usa alias opacos para cuentas; nunca publiques números completos, credenciales ni el original. Conserva unidades monetarias enteras y monedas separadas si no hay tipo de cambio verificable.

No operes inversiones ni transfieras dinero. Informa documentos ambiguos y tareas bloqueadas como tales. El perfil se usa bajo demanda con su propia sesión; no arranques otro proceso sobre el perfil personal ni otro gateway con el mismo bot.
