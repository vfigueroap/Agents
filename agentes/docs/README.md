## Elegir un dominio

Cada enlace lleva a sus instrucciones. Son definiciones de responsabilidad;
no implican que haya un agente conectado o ejecutándose.

| Necesidad | Dominio |
| --- | --- |
| Organización personal | [Personal](../agents/personal/AGENTS.md) |
| Aprender, enseñar y preparar trabajos | [Academic](../agents/academic/AGENTS.md), con perfiles de tutor y compañero |
| Modelar y analizar problemas de ingeniería | [Engineering](../agents/engineering/AGENTS.md) |
| Construir y revisar software | [Software](../agents/software/AGENTS.md) |
| Planificar sistemas e infraestructura | [Infrastructure](../agents/infrastructure/AGENTS.md) |
| Analizar información financiera | [Finance](../agents/finance/AGENTS.md) |
| Diseñar un negocio | [Business](../agents/business/AGENTS.md) |
| Preparar contenido y marketing | [Marketing](../agents/marketing/AGENTS.md) |
| Planificar ventas | [Commercial](../agents/commercial/AGENTS.md) |
| Investigar cuestiones legales | [Legal](../agents/legal/AGENTS.md) |
