# Catálogo canónico de skills

Cada carpeta contiene skill.yaml (contrato) y SKILL.md (procedimiento). El id es único globalmente. Se carga solo la skill necesaria; el exportador publica las skills declaradas por un agente sin concatenar sus cuerpos en las instrucciones iniciales. Los cinco nombres heredados permanecen migration_pending y no son seleccionables para ejecución. Los grupos no son agentes; personal usa shared.
