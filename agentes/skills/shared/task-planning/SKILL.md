# Planificar tareas

Skill procedimental escrita para esta arquitectura. Su estado implementado indica instrucciones disponibles, no ejecución autónoma ni integración comprobada.

1. Registrar el resultado verificable, alcance, entradas y salida esperada.
2. Identificar datos faltantes; avanzar solo en partes independientes.
3. Dividir por entregables; delegar únicamente si aporta aislamiento o paralelismo medible.
4. Comprobar disponibilidad de herramientas y presupuesto antes de proponer ejecución.
5. Cerrar con evidencia, limitaciones y pendientes; un YAML no acredita ejecución.
