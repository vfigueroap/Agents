# Revisar evidencia

Skill procedimental escrita para esta arquitectura. Su estado implementado indica instrucciones disponibles, no ejecución autónoma ni integración comprobada.

1. Registrar procedencia y fecha de cada afirmación material.
2. Distinguir documentos aportados de fuentes primarias verificadas.
3. No repetir cifras del contexto como resultados académicos verificados.
4. Informar contradicciones, incertidumbre y las comprobaciones pendientes.
