# Evaluaciones

Los escenarios YAML son criterios, no resultados de evaluaciones LLM. Las pruebas automatizadas en ../tests/ cubren los invariantes locales indicados como automated. No miden exactitud profesional ni conducta de un modelo. Las evaluaciones humanas o con modelos quedan pendientes; usar datos sintéticos y comparar calidad, precisión, costo, latencia, seguridad y confiabilidad antes de añadir agentes.
