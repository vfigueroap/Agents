# Reportes de Profesor-Tutor

Memoria local autorizada por el usuario. `MEMORIA.md` conserva hechos, decisiones y vínculos de cierre; `tareas/` contiene asignaciones y estados. Los informes deben indicar objetivo, fecha, responsable, clasificación local, fuentes, hallazgos, decisiones, comprobaciones, límites y próximos pasos.

El responsable es `tutor-memoria`. Consulta la [skill de memoria](../../.agents/skills/memoria-reportes/SKILL.md). Usa un archivo por tarea o análisis; no borres informes anteriores para actualizar una conclusión. Los datos de reportes están excluidos de Git, excepto este README. OneDrive puede sincronizarlos con la cuenta del usuario. No guardar credenciales.
