# Plugins de Compañero de Universidad

Usa solo los plugins pertinentes al objetivo: [catálogo del área](../conexiones/catalogo.json). Las instalaciones globales no se copian a este directorio.

La sesión inspeccionada dispone de GitHub, Google Drive, Gmail y Google Calendar con perfil de cuenta verificado el 2026-11-15; esto no comprueba cada operación ni garantiza que otra sesión los exponga. Los plugins de documentos, PDF, presentaciones y hojas de cálculo se seleccionan por el entregable. Verifica la disponibilidad antes de delegar.
