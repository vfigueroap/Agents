# MCP

No se han registrado servidores nuevos en el proyecto. Los perfiles nativos heredan los servidores y permisos de la sesión principal. Las carpetas por área documentan propósito y estado; no instalan servicios.

Consulta [conexiones/catalogo.json](../conexiones/catalogo.json). Para una conexión nueva, verifica fuente, configuración admitida por el host, autenticación y una prueba de lectura antes de declararla activa. Mantén secretos fuera de archivos del proyecto y no copies configuraciones globales que los incluyan.

Referencia de perfiles y herencia: [documentación oficial de subagentes de OpenAI](https://developers.openai.com/codex/subagents).
