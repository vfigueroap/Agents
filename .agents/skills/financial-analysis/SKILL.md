# Análisis financiero

1. Marcar datos ficticios, moneda, unidades, periodo y supuestos.
2. Separar hechos aportados de estimaciones; comprobar cálculos.
3. Incluir riesgos y sensibilidad; no prometer retornos.
4. Generar análisis o propuestas; nunca convertir consulta en orden de inversión, pago o transferencia.
