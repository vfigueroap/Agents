# Modelación técnica

1. Definir variables, unidades, restricciones y condiciones de borde.
2. Elegir un método acorde a la precisión requerida y registrar supuestos.
3. Comprobar dimensiones y un caso límite o una solución conocida.
4. Presentar sensibilidad y limitaciones; una simulación propuesta no es una validación experimental.
