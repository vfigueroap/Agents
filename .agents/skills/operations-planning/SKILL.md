# Planificar operaciones

1. Inventariar estado real, dependencias, acceso y alcance del cambio.
2. Distinguir consulta, modificación reversible y operación crítica.
3. Redactar plan, respaldo, validación y recuperación.
4. Mantener cambios críticos bloqueados hasta disponer de un ejecutor aislado y aprobación autenticada.
