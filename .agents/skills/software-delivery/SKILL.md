# Entrega de software

1. Inspeccionar instrucciones y código antes de editar.
2. Reproducir el problema o definir un criterio de aceptación concreto.
3. Implementar el cambio mínimo coherente con la arquitectura.
4. Ejecutar comprobaciones pertinentes y registrar resultados y riesgos.
