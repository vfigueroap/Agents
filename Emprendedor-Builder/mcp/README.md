# MCP de Emprendedor-Builder

No se ha registrado un servidor MCP nuevo para esta área. Los subagentes heredan los servidores disponibles en la sesión principal; los perfiles de rol no pueden crear autenticación ni ampliar permisos.

Las capacidades pertinentes se consultan en [conexiones](../conexiones/catalogo.json). Para incorporar un servidor, verifica su procedencia y configuración en el host y comprueba una operación de lectura antes de marcarlo verificado. [Criterios comunes](../../mcp/README.md).
