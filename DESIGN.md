# Dirección visual de las guías

Estilo predeterminado de Diagram Design, elegido por el usuario el 15 de noviembre
de 2026. Documento de consulta en español para el propietario del sistema.

Dial: ENERGY 1 / RHYTHM 2 / MOTION 1.

| Decisión | Valor y motivo |
| --- | --- |
| Fondo | #f5f5f5, deja leer diagramas largos sin superficies decorativas |
| Texto | #2d3142, jerarquía por peso y tamaño sobre el mismo fondo |
| Texto secundario | #4f5d75, separa explicaciones de nombres manteniendo contraste |
| Acento | #bf4520, señala únicamente el punto donde se ejecuta una tarea |
| Título | Instrument Serif, distingue el título editorial del contenido técnico |
| Nombres | Geist sans 600, facilita reconocer cada pieza al recorrer el mapa |
| Rutas | Geist Mono, distingue archivos y comandos del lenguaje corriente |
| Composición | Flujo principal de izquierda a derecha y referencias debajo |
| Espacio | Grupos separados por responsabilidad; márgenes en múltiplos de 4 |
| Bordes | Radio 6 y borde fino para agrupar, sin sombras ni gradientes |
| Movimiento | Documento estático; solo estados de foco, hover y pulsación |
| Tema | Fondo de papel fijo para leer e imprimir la misma figura |
| Identidad | Nombres humanos junto a rutas reales, como índice de taller |

Las fuentes incluyen alternativas del sistema si Google Fonts no está disponible.
No se usan logotipos, avatares, fotografías ni cifras de rendimiento.
